# ГРСС — мобільний переглядач

Офлайн-застосунок для перегляду бази ГРСС на телефоні (iPhone / Android).

Репозиторій містить **лише код** застосунку — жодних персональних даних.
Дані завантажуються на телефон окремим зашифрованим файлом `.grss`
(AES-256-GCM, ключ з пароля через PBKDF2-SHA256), який створює програма на ПК
(меню «Експорт для телефону»). Розшифрування відбувається тільки на пристрої.
